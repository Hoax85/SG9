# Sicherheit / Security

Bitte Sicherheitslücken **nicht** als öffentliches Issue melden, sondern über
„Report a vulnerability“ im Tab *Security* dieses Repositorys (GitHub Private Vulnerability Reporting).

Please do **not** report security issues as public issues. Use “Report a vulnerability”
in the *Security* tab of this repository instead.

Unterstützt wird jeweils die neuste Version. / Only the latest release is supported.
